# ساحات سياسية 5.0

نسخة مطورة من التطبيق تشمل:

- ساحات سياسية ومنشورات وتعليقات وإعجابات ودردشة نصية.
- رفع صور JPG/PNG/WEBP/GIF وفيديو MP4/WEBM/MOV مع المنشورات.
- حتى 4 ملفات في المنشور، وحتى 200MB لكل ملف.
- غرف دردشة صوتية مباشرة لكل ساحة باستخدام WebRTC.
- بث فيديو مباشر داخل كل ساحة باستخدام WebRTC.
- اختيار منفذ متاح تلقائياً إذا كان 3000 مشغولاً.

## تشغيل Windows

افتح PowerShell داخل مجلد المشروع:

```powershell
npm install
npm start
```

ثم افتح الرابط الذي يظهر في PowerShell، مثل:

```text
http://localhost:3000
```

## ملاحظات مهمة للبث والصوت

على `localhost` يسمح Chrome عادةً باستخدام الكاميرا والميكروفون. عند نشر التطبيق على الإنترنت يجب تشغيله عبر HTTPS.

الإصدار الحالي يستخدم WebRTC بنمط peer-to-peer وهو مناسب للاختبار والمجموعات الصغيرة. للنشر واسع النطاق والبث لعدد كبير من المشاهدين، استخدم خادم TURN وخادم SFU مثل LiveKit أو mediasoup أو Janus.

الملفات المرفوعة تحفظ داخل مجلد `uploads`.

قبل النشر العام، عيّن `JWT_SECRET` قويًا واستخدم قاعدة بيانات حقيقية وتخزينًا سحابيًا للوسائط.
