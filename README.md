# ساحات سياسية — الإصدار 7.0

نسخة مطورة تفصل واجهة المستخدم عن مركز الإدارة بالكامل.

## واجهة المستخدم `/`
- إنشاء غرف سياسية للمستخدمين النشطين.
- مالك الغرفة يستطيع تعديلها وحذفها وإدارة الأعضاء.
- إضافة أعضاء، تعيين مشرف غرفة، حظر عضو أو إزالته.
- مالك الغرفة ومشرفوها يستطيعون إدارة المشاركين في الصوت: كتم وإخراج.
- منشورات نصية وصور وفيديو حتى 4 ملفات، 200MB للملف.
- دردشة نصية وتعليقات وإعجابات وبلاغات.
- بث فيديو مباشر متعدد المشاركين: صاحب البث يدعو مستخدمًا بالاسم ليظهر معه كضيف، ويمكنه إزالة الضيف.
- لا تحتوي واجهة المستخدم على أدوات إدارة النظام.

## مركز الإدارة `/admin`
واجهة مستقلة تمامًا وبهوية مختلفة، لا تُفتح وظيفيًا إلا لحساب `admin`.
- إدارة المستخدمين والأدوار والإيقاف والحذف.
- إدارة الغرف وفتحها وإغلاقها وحذفها.
- مراجعة المنشورات والتعليقات ورسائل الدردشة وحذفها.
- البلاغات وسجل الإجراءات الإدارية.
- مشاهدة الجلسات الحية والغرف الصوتية النشطة.
- مراقبة مباشرة للبث والصوت من لوحة الإدارة دون إضافة حساب الأدمن إلى قوائم المشاركين المعروضة للمستخدمين.
- قطع البث، إزالة ضيف من البث، كتم أو إخراج متحدث من الغرفة الصوتية.

## لا يوجد تسجيل
تم حذف نظام تسجيل وأرشفة الصوت والفيديو بالكامل. لا يوجد `MediaRecorder`، ولا API للتسجيلات، ولا جداول تسجيلات في schema الجديد. الإشراف الإداري مباشر فقط أثناء الجلسة.

## التشغيل
1. أنشئ ملف `.env` وأضف PostgreSQL:

```env
DATABASE_URL=postgresql://USER:PASSWORD@HOST:5432/DBNAME
JWT_SECRET=change-this-to-a-long-random-secret
PORT=3000
```

2. ثبّت وشغّل:

```powershell
npm install
npm run check
npm start
```

السيرفر يجرب منافذ لاحقة تلقائيًا إذا كان المنفذ المطلوب مستخدمًا.

## المسارات
- المستخدم: `http://localhost:PORT/`
- الإدارة: `http://localhost:PORT/admin`
- فحص الصحة: `http://localhost:PORT/api/health`

## ملاحظات الإنتاج
WebRTC هنا يعتمد STUN واتصال peer-to-peer. للاستضافة العامة وعدد مستخدمين كبير استخدم TURN وSFU مثل LiveKit/mediasoup/Janus بدل Mesh P2P.
